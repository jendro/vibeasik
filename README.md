# vibeasik

> Lapisan standar untuk kode buatan AI. Jalan di laptop atau dev server Anda, dipanggil agent lewat MCP.

**vibeasik Community** adalah inti open source vibeasik: scan & deteksi stack, audit dasar dengan 85 rule,
manajemen port & runner, peta rute & kode, Pusat Pengetahuan lokal, server MCP dasar, dan Studio web.
Fitur Pro (deep audit, AI review, pegawai AI, orchestrator, Galeri Desain, …) tersedia di build resmi
dan terbuka sesuai paket langganan.
